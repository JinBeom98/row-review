# 상품 행 검수 (row-review)

엑셀에 작성된 상품 정보를 **한 행씩 크게 보면서** 단가·상시가·할인가 등을 검증하고, 행 단위로 판정과 메모를 남기는 정적 웹 도구입니다.

- 서버 없이 HTML 파일 하나로 동작합니다.
- 엑셀은 **사용자의 브라우저 안에서만** 읽으며, 어디로도 전송되지 않습니다.

## 사용법
1. 페이지를 열고 **엑셀 열기**를 누르거나 파일을 화면에 끌어다 놓습니다. (`.xlsx` / `.xls` / `.csv`, 파일 1개)
2. 첫 행은 헤더로 읽고, 2행부터 한 행씩 표시합니다.
3. 각 행을 판정(정상 / 이슈 / 보류)하고 메모를 남깁니다. 값을 클릭하면 문제 항목으로 '표시'됩니다.
4. **검수 결과 내보내기**를 누르면 원본 열에 검수상태, 자동검증, 메모 열을 붙인 xlsx를 내려받습니다.

체험용 샘플: [`sample_products.xlsx`](sample_products.xlsx) (더미 데이터 30행, 의도적 오류 10건)

## 단축키
| 키 | 동작 |
|---|---|
| `←` `→` | 이전 / 다음 행 |
| `1` `2` `3` | 정상 / 이슈 / 보류 판정 (`0` 해제) |
| `N` | 다음 미검수 행 |
| `M` | 메모 입력 |
| `/` | 검색 |

## 자동 검증 규칙
'열 매핑 · 검증 규칙' 화면에서 켜고 끄거나 기준값을 바꿀 수 있습니다.

- 가격이 비어 있거나, 숫자가 아니거나, 0 이하이면 오류
- 할인가 > 상시가이면 오류, 할인가 = 상시가이면 경고
- 단가 > 할인가(역마진)이면 오류
- 계산 할인율이 허용 범위(기본 0~70%)를 벗어나면 경고
- 기재 할인율과 계산 할인율이 허용치(기본 1%p)보다 다르면 오류
- 필수 열이 비어 있으면 오류, 상품 이미지가 없으면 경고

단가·상시가·할인가·할인율 열은 열 이름으로 자동 지정합니다. 예: 공급가 → 단가, 정상가·판매가 → 상시가, 행사가 → 할인가.

## 상품 이미지
- 셀 위에 삽입된 그림과 Excel 365의 '셀에 그림 배치' 그림을 해당 행의 이미지로 표시합니다.
- 이미지 URL이 들어 있는 셀도 그림으로 표시합니다.

## 참고
- 판정, 메모, 표시한 항목은 브라우저(localStorage)에 자동 저장됩니다. 같은 파일을 다시 열면 이어서 검수할 수 있습니다.
- 내보낸 xlsx에는 이미지가 포함되지 않습니다.
- 엑셀 처리 라이브러리(SheetJS, JSZip)는 CDN에서 불러오므로 인터넷 연결이 필요합니다.
- 샘플 재생성: `python make_sample.py sample_products.xlsx` (openpyxl, pillow 필요)
